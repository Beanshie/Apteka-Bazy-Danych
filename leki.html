Łączenie z API...

Nie udało się połączyć z API (http://localhost:8080/api/v1/leki)

Możliwe przyczyny i rozwiązania:

  • Brak konfiguracji CORS w Spring Boot: Dodaj adnotację @CrossOrigin(origins = "*") nad kontrolerem LekController.
  • Aplikacja Spring Boot nie działa: Upewnij się, że serwer działa na porcie 8080.
  • Spring Security blokuje żądanie: Endpoint zwraca kod statusu 401 lub 403. Wyłącz autoryzację dla ścieżki GET lub przekaż nagłówek Bearer Token.
